## 1. Purpose
Defines ongoing performance monitoring of AI systems in production and the response to monitoring alerts.

## 2. Performance monitoring
2.1 Each production system has a monitoring configuration proportionate to its risk level. High-risk systems are monitored most frequently.

2.2 Monitoring tracks predictive performance and input-distribution stability over time. A monitoring report is produced each cycle and retained.

2.3 Alerts are graded (e.g. informational / warning / critical). Warning and critical alerts trigger investigation by the Technical Owner within a defined window.

## 3. Incident response
3.1 A confirmed material degradation or incident is logged and escalated. Where remediation is not viable within the agreed window, the system is referred for a retirement review.

## 4. Scope note
4.1 This procedure covers performance and stability monitoring. It does not define fairness or bias metrics or their monitoring; responsible-use monitoring is out of scope of this document.
