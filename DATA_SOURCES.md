# Data sources

For the project report's references section (instructor requirement item 4:
"Source URL for the data used").

## 1. ISO/IEC 42001:2023 — Information technology — Artificial intelligence —
Management system

Standard text used for the Annex A control catalogue (38 controls, A.2–A.10), the
knowledge-graph nodes, and the per-system control mapping. Accessed through the Turkish
adoption **TS ISO/IEC 42001:2024** (Türk Standardları Enstitüsü, March 2024).

- Publisher page: https://www.iso.org/standard/81230.html
- Turkish adoption (TSE): https://www.tse.org.tr

Licensed, copyright-protected standard. No clause text is reproduced in this project;
only control identifiers, titles and clause references are cited, with control
descriptions written in the author's own words.

## 2. AI system inventory (institutional data)

The AI system inventory is **institutional data**, adapted from the AI service inventory
of the organisation where the system is deployed. Per the instructor's note, the source
URL requirement does not apply to institutional data.

The inventory used in this project has been **adapted and de-identified**:
- the institution is not named;
- organisational unit names are generalised;
- system descriptions are rewritten at use-case level rather than reproducing internal
  project text;
- compliance attestations, review dates, stewardship and data-quality tags are
  illustrative values created for the demonstration, not the organisation's real
  compliance findings.

No customer, employee or other individual is identified. No real compliance gap findings
of the institution are disclosed.

## 3. Internal policy corpus

The Layer 2 policy corpus documents are illustrative drafts written for this project.
The organisation's real policy and procedure set is under development; the
`procedure_responsibility_map.csv` in `04_ground_truth/` records which ISO 42001 controls
require a new procedure or an addition to an existing one, and which directorate is the
recommended owner.
